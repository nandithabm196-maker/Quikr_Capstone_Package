This Week 6 capstone project integrates the major data-science concepts covered during the Yuva Intern Virtual Data Science with Python internship using a Quikr used-car listings dataset. The project begins with data acquisition and systematic preprocessing. The original dataset contained 892 records and six attributes: vehicle name, company, year, price, kilometres driven and fuel type. Data-quality issues included duplicate records, missing values, mixed text and numeric formats, invalid year entries, non-numeric price entries such as “Ask For Price”, and inconsistent mileage values. After cleaning and validation, 725 analysis-ready records remained.

The project then extends the cleaned dataset into a complete data-science pipeline. Exploratory data analysis is used to study price distributions, mileage, vehicle age, fuel type and year-wise price patterns through visualizations. Feature engineering creates vehicle age and kilometres-per-year variables. Supervised learning models are trained to predict used-car prices, with Linear Regression, Ridge Regression, Random Forest and Gradient Boosting considered as candidate models. Performance is evaluated using Mean Absolute Error, Root Mean Squared Error and R² rather than relying on a single metric. An optional K-Means clustering stage provides an unsupervised view of vehicle segments based on year, mileage and price.

The project emphasizes reproducibility, clear preprocessing decisions, appropriate evaluation and interpretation of model limitations. The final outputs include cleaned data, exploratory charts, model-comparison metrics, prediction plots, clustering results and a structured Python implementation. The work demonstrates how raw, inconsistent real-world data can be transformed into useful predictive and descriptive insights using Python and machine-learning techniques.
